# 모기담곰 길드 홈페이지

테일즈런너 모기담곰 길드를 위한 GitHub Pages용 정적 웹사이트입니다.

## 배포

1. ZIP 파일 압축 해제
2. GitHub에서 공개 저장소 생성
3. `index.html`, `style.css`, `script.js`, `assets/` 폴더를 저장소 최상위에 업로드
4. **Settings → Pages → Build and deployment → Deploy from a branch** 선택
5. `main` 브랜치, `/(root)`를 선택하고 저장
6. 발급된 `https://사용자명.github.io/저장소명/` 주소 접속

## 길드 초대 링크 설정 (중요)

`script.js` 파일 맨 위의 아래 항목에 실제 링크를 입력하세요.

```js
const GUILD_CONFIG = {
  discordUrl: 'https://discord.gg/실제초대코드',
  openChatUrl: 'https://open.kakao.com/o/실제초대코드'
};
```

아직 초대 링크가 없어 기본값은 공백입니다. 공백인 경우 방문자에게 안내 메시지만 표시합니다.

## 기능

- 커스텀 입장 화면 (해당 브라우저 탭에서 재방문 시 생략)
- 달과 하얀 농담곰 풍 마스코트, 별빛 배경, 스크롤 등장 효과
- 모바일/태블릿/PC 반응형
- 한국 시각 기준 다음 길퀘 시작(00:10 또는 23:00)까지 시간 표시
- 규칙 10개 + 상세 보기 버튼
- 효과음 켜기/끄기 (외부 음원 없음, 초기 비활성)
- 밤/새벽 테마 전환
- 키보드 `asa` 이스터에그 (모바일 외장 키보드도 가능)
- 공유 미리보기 메타 데이터

**주의:** '다음 길퀘 시작' 카운트다운은 매일 시작 시각만 계산하며, 실제 길퀘 운영 요일이나 진행 여부를 확인하는 기능은 아닙니다.

폰트는 Google Fonts를 사용하며, 네트워크가 없으면 시스템 기본 글꼴로 표시됩니다. 외부 음악·실제 초대 URL은 임의로 넣지 않았습니다.

## 캐릭터 디자인

기존 갈색 테디베어 이미지를 하얗고 둥근 농담곰 느낌의 직접 제작한 SVG 캐릭터로 교체했습니다. `assets/mascot.svg`, `assets/favicon.svg`를 변경하면 다른 캐릭터 이미지로 교체할 수 있습니다.
