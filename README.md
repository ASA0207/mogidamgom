# 모기담곰 길드 홈페이지

테일즈런너 모기담곰 길드를 위한 GitHub Pages용 정적 웹사이트입니다.

## 배포

1. ZIP 파일 압축 해제
2. GitHub에서 공개 저장소 생성
3. `index.html`, `style.css`, `script.js`, `assets/` 폴더를 저장소 최상위에 업로드
4. **Settings → Pages → Build and deployment → Deploy from a branch** 선택
5. `main` 브랜치, `/(root)`를 선택하고 저장
6. 발급된 `https://사용자명.github.io/저장소명/` 주소 접속

## 길드 초대 링크 설정 (중요)

`script.js` 파일 맨 위의 아래 항목에 실제 링크를 입력하세요.

```js
const GUILD_CONFIG = {
  discordUrl: 'https://discord.gg/실제초대코드',
  openChatUrl: 'https://open.kakao.com/o/실제초대코드'
};
```

아직 초대 링크가 없어 기본값은 공백입니다. 공백인 경우 방문자에게 안내 메시지만 표시합니다.

## 기능

- 커스텀 입장 화면 (해당 브라우저 탭에서 재방문 시 생략)
- 달과 하얀 농담곰 풍 마스코트, 별빛 배경, 스크롤 등장 효과
- 모바일/태블릿/PC 반응형
- 한국 시각 기준 다음 길퀘 시작(00:10 또는 23:00)까지 시간 표시
- 규칙 10개 + 상세 보기 버튼
- 업로드 음원 **최예나 - SMILEY (Feat. BIBI)** 내장 (`assets/smiley.mp3`, 약 6.7MB)
- 시작 시 `음악과 함께 입장` / `조용히 입장` 선택, 상단 음악 일시정지 및 음량 조절 (기본 22%)
- 브라우저 정책에 따라 클릭하기 전에는 자동재생되지 않으며, 새 탭에서 입장 화면을 거치지 않으면 상단 음표 버튼으로 시작 가능
- 배경음악 재생 중에도 키보드 `asa` 이스터에그 사용 가능
- 밤/새벽 테마 전환
- 키보드 `asa` 이스터에그 (모바일 외장 키보드도 가능)
- 공유 미리보기 메타 데이터

**주의:** '다음 길퀘 시작' 카운트다운은 매일 시작 시각만 계산하며, 실제 길퀘 운영 요일이나 진행 여부를 확인하는 기능은 아닙니다.

폰트는 Google Fonts를 사용하며, 네트워크가 없으면 시스템 기본 글꼴로 표시됩니다. 사용자가 제공한 음원을 포함했으며, 실제 초대 URL은 임의로 넣지 않았습니다. 해당 음원의 공개 배포 권한은 업로더가 직접 확인해야 합니다.

## 캐릭터 디자인 - 최종 적용

사용자가 제공한 원본 농담곰 이미지 네 장을 `assets/`에 포함했습니다.

- `mosquito-bear.png` : 모기 옷 농담곰 (메인 비주얼)
- `swim-bear.png` : 수영 농담곰 (길드 소개)
- `running-bear.png` : 뛰는 농담곰 (이스터에그/파비콘)
- `duck-bear.png` : 오리 농담곰 (시작 화면/가입 섹션)

캐릭터 카드 4종을 클릭하면 별빛 애니메이션이 실행됩니다. 캐릭터 이미지는 `index.html`에서 경로를 교체할 수 있습니다. 원본의 배경이 흰 이미지 3장은 홈페이지 배경과 어울리도록 흰 배경만 투명화했습니다.

**공개 배포 유의:** 제공받은 캐릭터 이미지와 상업 음원에는 별도 저작권이 있을 수 있으므로, GitHub Pages 공개 사용 전 이용 허락과 권리를 확인하세요.
